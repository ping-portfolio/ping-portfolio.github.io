AGENT + SKILL / SYSTEM

封装 Skill，
Codex 执行。

Skill 负责“怎么做”和“如何验收”；Agent 负责读取状态、调用工具、重试和留痕。它不是一次性的 Prompt，而是一套可恢复、可追踪的生产系统。

01 / SKILL PACKAGE规则是智能体的操作手册

把画布尺寸、模块角色、品牌与产品锁、视觉规范、禁止项和验收标准写入 Skill，让每次执行遵循同一套设计判断。

02 / SUBAGENT COORDINATION主 Agent 拆任务，Subagents 并行协作

启动时先定义每个 Subagent 的角色、输入、交付格式与验收条件；独立任务并行派发，有依赖的任务按状态接力。每个 Subagent 只处理明确交付物并回传结果，由主 Agent 合并与处理冲突。

03 / QC & RETRY LOOP不合格结果自动回路

逐图检查产品事实、文字、尺寸与套图连续性；未过门槛就调整参数并重试，连续失败才转入人工确认。

04 / TRACEABLE OUTPUT无人值守，过程仍可追踪

输入、Prompt、版本、结果和错误记录统一归档。设备与调用服务在线时，队列可昼夜持续运行，任何异常都不会被静默跳过。

让新品素材，从文件夹走向可检索的工作台。

解决问题

实现方式
按产品编码、品类和标签组织素材，支持跨产品筛选与原比例预览，让设计参考和已有素材更容易复用。

02 / AMAZON VISUAL MANAGEMENT

亚马逊生成管理

按产品看全套图片，让生成后的整理更清楚。

解决问题
主图、A+、场景图和尺寸图分散存放，难以快速查看同一产品的完整视觉素材。
实现方式
以产品编码串联图片，结合图位分类、搜索与标签筛选，集中查看和对照各类生成结果。
